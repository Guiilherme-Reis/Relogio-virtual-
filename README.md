# ⏱️ Relógio Virtual

Um relógio digital desenvolvido com **HTML, CSS e JavaScript**, com o objetivo de praticar os fundamentos do desenvolvimento web e construir uma aplicação funcional, com interface visual agradável e execução diretamente no navegador.

O projeto faz parte da minha jornada de aprendizado em programação, na qual busco transformar conhecimentos teóricos em aplicações práticas, aprimorando minhas habilidades em desenvolvimento front-end.

## 🚀 Demonstração

**Acesse o projeto online:**

🔗 [Visualizar Relógio Virtual](https://guiilherme-reis.github.io/Relogio-virtual-/)

## 📸 Sobre o projeto

O Relógio Virtual é uma aplicação web que apresenta as horas em uma interface digital, utilizando JavaScript para atualizar as informações dinamicamente.

A proposta é desenvolver uma aplicação simples, mas funcional, explorando a integração entre estrutura, estilização e lógica de programação.

## 🛠️ Tecnologias utilizadas

- **HTML5:** estruturação e organização dos elementos da página.
- **CSS3:** estilização da interface e apresentação visual.
- **JavaScript:** implementação da lógica e atualização dinâmica do relógio.
- **Git e GitHub:** versionamento e gerenciamento do código-fonte.
- **GitHub Pages:** hospedagem e publicação do projeto na internet.

## 💡 Conceitos praticados

Durante o desenvolvimento, foram trabalhados conceitos fundamentais do desenvolvimento web, como:

- Estruturação de páginas com HTML.
- Organização e aplicação de estilos com CSS.
- Manipulação de elementos da página com JavaScript.
- Utilização de funções e recursos temporais para atualização do relógio.
- Integração entre HTML, CSS e JavaScript.
- Organização de arquivos e diretórios.
- Versionamento de código com Git e GitHub.
- Publicação de aplicações estáticas com GitHub Pages.

## ▶️ Como executar o projeto localmente

Caso queira executar o projeto no seu computador:

1. Clone este repositório:

   ```bash
   git clone https://github.com/Guiilherme-Reis/Relogio-virtual-.git
   ```

2. Entre na pasta do projeto:

   ```bash
   cd Relogio-virtual-
   ```

3. Abra o arquivo `index.html` no navegador.

Não é necessário instalar dependências para executar a versão estática do projeto.
